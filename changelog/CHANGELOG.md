# 更新履歴

## v1.0.0 - 2026-10-13

- Windows 11 の Fluent Design System（Mica・アクリル）による半透明で奥行きのある画面
- マスターパスワードで暗号化した保管庫に、ログイン情報（サービス名・ID・パスワード・URL・カテゴリ・お気に入り）を保存
- 一覧の「ID」「パスワード」ボタンでコピー。検索欄で `Enter` を押すと選択中（先頭）のパスワード、`Shift+Enter` で ID をコピー。コピーした内容は 30 秒後に自動で消去
- 追加・編集・削除（削除は確認あり）。URL を入れるとサービス名を自動入力、カテゴリの候補表示
- 強いパスワードの自動生成（文字数・文字の種類を指定可能）と強度表示
- セキュリティ診断（使い回し・短いパスワードの検出。項目から編集画面を開ける）
- オートタイプ（`Ctrl+Alt+V` で選択画面を開き、ID → Tab → パスワード → Enter を自動入力）
- 自動ロック（無操作時間を選択可能、Win+L・スリープで即時）と `Ctrl+L` の手動ロック
- 暗号化したままのエクスポート / インポート
- お気に入り・カテゴリでの絞り込み、ログインページを開くボタン、右クリックメニュー
- 起動時のアップデート確認（「アップデートする / しない」を選択。ダウンロードしたファイルを検証してから自動でインストールし、再起動）
