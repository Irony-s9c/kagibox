# KagiBox

Windows 11 用のパスワード管理ソフトです。

## 概要

KagiBox は、Web サービスなどの ID とパスワードをまとめて管理するソフトです。

- 登録したデータは、お使いのパソコンの中にだけ暗号化して保存します。インターネット上のサーバーには送信しません。
- アカウントの作成や利用登録は必要ありません。
- サービス名を数文字入力して Enter キーを押すだけで、パスワードをコピーできます。

## 動作環境

- Windows 11（64 ビット版）
- Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）

## ダウンロード

[Releases](https://github.com/Irony-s9c/kagibox/releases/latest) のページから `KagiBox-Setup-1.1.0.exe` をダウンロードしてください。

現在のバージョンは 1.1.0 です。

Releases のページに表示される「Source code」は GitHub が自動で付けるもので、中身はこの説明書だけです。ダウンロードの必要はありません。

## インストールと起動

1. ダウンロードした `KagiBox-Setup-1.1.0.exe` を実行し、画面の案内に従ってインストールします。
2. 初めて起動すると、マスターパスワードの設定画面が表示されます。8 文字以上で設定してください。

マスターパスワードは、KagiBox を開くためのただ一つの鍵です。忘れてしまうと作者にも元に戻すことができず、登録したデータは二度と開けなくなります。必ず控えておいてください。

## 使い方

### アカウントを登録する

「追加」ボタン（または Ctrl+N）で登録画面を開き、サービス名・ID・パスワードを入力して保存します。
URL を入力すると、サービス名が空欄の場合は自動で入力されます。

### パスワードをコピーする

検索欄にサービス名の一部を入力して Enter キーを押すと、一覧の先頭にあるアカウントのパスワードがコピーされます。Shift+Enter キーでは ID がコピーされます。

コピーした内容は、30 秒後にクリップボードから自動で消去されます。

### ログイン画面に自動で入力する

ブラウザーなどの ID 入力欄をクリックしてから Ctrl+Alt+V キーを押し、アカウントを選びます。ID、Tab キー、パスワード、Enter キーの順に自動で入力されます。

ブラウザーの拡張機能は必要ありません。ゲームのランチャーなど、デスクトップアプリのログイン画面でも使用できます。

### キー操作の一覧

| 操作 | キー |
|---|---|
| パスワードをコピー | 検索して Enter |
| ID をコピー | 検索して Shift+Enter |
| ログイン画面に自動入力 | Ctrl+Alt+V |
| アカウントを追加 | Ctrl+N |
| 検索欄へ移動 | Ctrl+F |
| 一覧の選択を移動 | ↑ / ↓ |
| すぐにロック | Ctrl+L |
| 画面を閉じる・検索をやめる | Esc |

## 主な機能

- 強いパスワードの自動生成（強さの目安を表示）
- 2 段階認証のワンタイムパスワードの表示（シークレットキー、または `otpauth://` で始まる URL を貼り付けて登録）
- お気に入りとカテゴリによる絞り込み
- 使い回しているパスワード、短いパスワードの確認
- 暗号化したままのバックアップ（書き出し・読み込み）
- 新しいバージョンのお知らせと自動更新（更新するかどうかはその都度選べます）

## 安全性について

- 登録したすべての項目（サービス名、ID、パスワード、2 段階認証のシークレットキーなど）を、アカウントごとに AES-256-GCM で暗号化して保存します。暗号化していない状態でディスクに書き込むことはありません。
- 暗号化に使う鍵は、マスターパスワードから Argon2id（メモリ 64 MiB、反復 3 回、並列度 4）で作ります。鍵そのものはどこにも保存しません。
- パスワードの復号は、コピー・表示・自動入力の操作をしたときに、その 1 件についてだけ行います。
- 次のときに自動でロックします。
  - 一定時間操作がなかったとき（初期設定は 5 分。1・5・15・30・60 分、または「ロックしない」から選べます）
  - Windows をロックしたとき（Win+L）
  - パソコンがスリープしたとき
- 通信を行うのは、新しいバージョンがあるかを GitHub に確認するときだけです。この確認は設定で止めることができます。

## データの保存場所

| 内容 | 場所 |
|---|---|
| 登録データ（暗号化済み） | `%LOCALAPPDATA%\KagiBox\vault.kagibox` |
| 設定（パスワードなどは含みません） | `%LOCALAPPDATA%\KagiBox\settings.json` |

別のパソコンへ移すときは、バックアップの書き出しを使うか、`vault.kagibox` をコピーしてください。

## 注意事項

- Windows Hello によるロック解除には対応していません。
- 自動入力と、Windows のロック・スリープの検知には、キーボードの監視機能を使っています。セキュリティソフトや会社のパソコンの管理設定によっては動作しないことがあります。使用できるかどうかは設定画面に表示されます。
- このソフトにはコード署名をしていないため、初めてインストーラーを実行したときに「Windows によって PC が保護されました」と表示されます。「詳細情報」をクリックし、「実行」を選ぶとインストールできます。
- ブラウザーがダウンロードを止めた場合は、ダウンロード一覧のメニュー（…）から「保存」を選び、続けて「保持する」を選んでください。

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から KagiBox を選び、アンインストールしてください。

登録データ（`%LOCALAPPDATA%\KagiBox`）は削除されずに残ります。不要な場合は手動で削除してください。
