# KagiBox

KagiBox は、Windows 11 用のローカル完結型パスワードマネージャーです。
ログイン情報はマスターパスワードで暗号化した 1 つのファイルとして PC の中にだけ保存し、クラウド同期やテレメトリ（利用状況の送信）は行いません。

## 主な機能

- **Fluent Design System**: Windows 11 の Mica・アクリルを使った、半透明で奥行きのある画面です。
- **暗号化保管庫**: すべての項目を AES-256-GCM で暗号化して保存。マスターキーは Argon2id で導出し、ディスクには書き込みません。
- **すばやいコピー**: 検索欄にサービス名を入れて `Enter` でパスワード、`Shift+Enter` で ID をコピー。コピーした内容は 30 秒後に自動で消去します。
- **パスワード生成**: 文字数と文字の種類を選んで強いパスワードを生成し、強度を表示します。
- **セキュリティ診断**: 使い回しや短いパスワードを見つけて知らせます。
- **オートタイプ**: ログイン画面で `Ctrl+Alt+V` を押してアカウントを選ぶと、ID → Tab → パスワード → Enter を自動入力します。
- **自動ロック**: 操作がない時間（選択可能）や、Win+L・スリープで自動的にロックします。`Ctrl+L` ですぐにロックできます。
- **バックアップ**: 暗号化したままエクスポート / インポートできます。
- **整理**: お気に入り・カテゴリでの絞り込み、ログインページを開くボタン。
- **自動アップデート**: 起動時に新しいバージョンを確認し、選択するだけでインストールと再起動まで行います（ダウンロードしたファイルは改ざんがないか検証します）。
