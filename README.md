# KagiBox

Windows 11 のためのパスワードマネージャーです。保管庫はあなたの PC の中にしかありません。

アカウントもクラウドも使いません。KagiBox が外と通信するのは、新しいバージョンがあるかを GitHub に確かめるときだけです。サービス名を数文字打って `Enter` を押せば、パスワードがクリップボードに入り、30 秒後に消えます。毎日使う道具なので、手数が少ないことを一番に考えて作りました。

**[最新版をダウンロード](https://github.com/Irony-s9c/kagibox/releases/latest)**　`KagiBox-Setup-<バージョン>.exe`

| | |
|---|---|
| 対応 OS | Windows 11（64 bit） |
| 必要なもの | Microsoft Edge WebView2 Runtime（Windows 11 には標準で入っています） |
| 料金 | 無料 |

## 使い始める

1. インストーラーを実行します。
2. 最初の起動でマスターパスワードを決めます（8 文字以上）。
   このパスワードは作者を含め誰にも復元できません。忘れると保管庫は開けなくなります。
3. `Ctrl+N` でアカウントを登録します。URL を入れるとサービス名は自動で埋まります。

あとは検索欄に `ama` と打って `Enter`。それだけで Amazon のパスワードがコピーされます。

## ふだんの操作

| やりたいこと | 操作 |
|---|---|
| パスワードをコピー | 検索して `Enter` |
| ID をコピー | 検索して `Shift+Enter` |
| ログイン画面に直接入力 | ID 欄をクリック → `Ctrl+Alt+V` → アカウントを選ぶ |
| 2 段階認証のコードをコピー | 一覧の 6 桁のコードをクリック |
| ログインページを開く | 一覧の右端のボタン |
| 一覧をキーボードで移動 | 検索欄で `↓`、続けて `↑` `↓` |
| 新規登録 | `Ctrl+N` |
| 検索欄へ移動 | `Ctrl+F` |
| すぐにロック | `Ctrl+L` |

`Ctrl+Alt+V` の自動入力は「ID → Tab → パスワード → Enter」の順に入力します。ブラウザ拡張は要りません。デスクトップアプリやゲームのランチャーでもそのまま使えます。

## できること

- パスワードの生成と強度の表示
- 2 段階認証（TOTP）のコード表示。シークレットか `otpauth://` の URL を貼るだけで登録できます
- お気に入り・カテゴリでの絞り込み。同じサービスの複数アカウントはまとめて表示します
- セキュリティ診断。使い回しているパスワードと短いパスワードを一覧にします
- 暗号化したままのバックアップ（エクスポート / インポート）
- アプリ内アップデート。新しいバージョンがあれば知らせ、選んだときだけ入れ替えます

## 保管庫の中身をどう守っているか

数字はすべて現在の実装の値です。

- **暗号化**　アカウントごとに、サービス名・ID・パスワード・2 段階認証のシークレットなど全項目をまとめて AES-256-GCM で暗号化します。平文の項目は 1 つもディスクに書きません。
- **鍵の導出**　マスターパスワードから Argon2id（メモリ 64 MiB、反復 3、並列度 4）で鍵を作ります。鍵そのものは保存しません。
- **復号は 1 件ずつ**　一覧に出すのはサービス名と ID だけです。パスワードはコピー・表示・自動入力の瞬間に、その 1 件だけを復号します。
- **クリップボード**　コピーしたパスワードと認証コードは 30 秒で消去します。
- **自動ロック**　無操作が続いたとき（既定 5 分。1 / 5 / 15 / 30 / 60 分、または「しない」から選択）、`Win+L` を押したとき、スリープしたときに、鍵をメモリから捨てます。
- **通信**　アップデート確認で GitHub API に問い合わせる以外、通信はしません。アイコンやフォントも同梱しているので、オフラインでも見た目は変わりません。設定から確認自体を止めることもできます。

## データの場所

| ファイル | 場所 |
|---|---|
| 保管庫（暗号化済み） | `%LOCALAPPDATA%\KagiBox\vault.kagibox` |
| 設定（秘密情報は含みません） | `%LOCALAPPDATA%\KagiBox\settings.json` |

PC を移行するときは、アプリのエクスポート機能を使うか、`vault.kagibox` をそのままコピーしてください。

## 既知の制限

- Windows Hello でのロック解除には、まだ対応していません。
- 自動入力と `Win+L` / スリープの検知はキーボードフックを使います。セキュリティソフトや会社の管理ポリシーで制限された PC では動かないことがあります。使えるかどうかは設定画面に表示されます。

## インストール時の警告について

インストーラーにはコード署名をしていないため、初回は「Windows によって PC が保護されました」と表示されます。「詳細情報」→「実行」で進めます。
ブラウザがダウンロードを止めた場合は、ダウンロード一覧の「…」から「保存」→「保持する」を選んでください。

## アンインストール

「設定」→「アプリ」→「インストールされているアプリ」から削除できます。
保管庫ファイルは残します。不要なら `%LOCALAPPDATA%\KagiBox` を手で削除してください。
